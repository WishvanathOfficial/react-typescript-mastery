# Chapter 2 — React + TypeScript Project Setup

A strong React application starts with a project foundation you understand.
This chapter explains the files and tools in a modern Vite + React + TypeScript
project, then puts that understanding to work in a Company Team Dashboard.

## Learning objectives

By the end of this chapter, you should be able to:

- describe the roles of Node.js, npm, Vite, React, and TypeScript;
- explain the purpose of common generated files and folders;
- read `package.json`, distinguish dependency types, and run npm scripts;
- explain common TypeScript configuration options and split configs;
- create a reusable, typed React component and organize a small feature;
- build and preview a Company Team Dashboard.

## Suggested study flow

Watch the lesson, inspect the matching files in a Vite React TypeScript project,
and run the commands yourself. Build the dashboard incrementally, then explain
the project structure and build workflow without looking at the notes.
