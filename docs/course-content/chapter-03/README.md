# Chapter 3 — JSX with TypeScript

JSX connects JavaScript and TypeScript expressions to the user interface. This
chapter explains how JSX is transformed, its syntax rules, typed attributes,
component children, and the `React.ReactNode` type. The chapter project brings
these ideas together in a Course Landing Section.

## Learning objectives

By the end of this chapter, you should be able to:

- explain what JSX is and how build tooling transforms it;
- write valid JSX using fragments, expressions, and correctly closed elements;
- render values and arrays, including lists with stable keys;
- use JSX attributes and pass type-safe props to components;
- accept and type children with `ReactNode`;
- compose a small Course Landing Section from focused components.

## Suggested study flow

Read each section and type the examples into a React TypeScript project. Try a
small intentional type or JSX error, read the diagnostic, and correct it.
Complete the project, then answer the review questions without looking at the
answers.
