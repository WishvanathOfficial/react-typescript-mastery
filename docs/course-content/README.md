# Course content

Course notes and activities live in numbered chapter folders. Each published
chapter should provide:

- `README.md` — chapter overview, learning objectives, and links to its material;
- `notes.md` — the written lesson content and examples;
- `exercises.md` — practical work with hints and a completion checklist;
- `interview-questions.md` — review questions with concise answers.

Keep content in Git, use relative links, and add a chapter folder when it is
ready for learners. See the [development roadmap](../ROADMAP.md) for the
publishing workflow. Published chapters include
[Chapter 1](./chapter-01/README.md),
[Chapter 2](./chapter-02/README.md),
[Chapter 3](./chapter-03/README.md), and
[Chapter 4](./chapter-04/README.md).
